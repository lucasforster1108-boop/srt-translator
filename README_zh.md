# srt-translator

我老是碰到同一个问题：片子有字幕，就是语种不对。日语片配日语字幕，别的全是英文字幕，看不懂。为一个字幕文件找人工翻译不现实，把 800 条字幕一条条粘进网页翻译器更折腾。

所以写了这个离线小工具：把现成的 `.srt` 字幕文件翻成你能看懂的语言。它用 [Argos Translate](https://github.com/argosopentech/argos-translate) 在你自己电脑上翻译——模型是本地的，翻译过程不联网——时间轴一条不动地原样保留，输出一份新字幕。还带双语模式：同一条字幕里译文在上、原文在下。

文件不出你的电脑。对某些字幕收藏来说，这一点本身就是意义所在。

## 说人话就是

很多成人视频——尤其是日系的——自带字幕，但只有日语或英语。看不懂的话，台词全靠猜，剧情丢一半。

字幕文件（就是那个 `.srt`）没什么神秘的：它就是一份带时间的台词本，写着「第几秒，说哪句话」。这个工具做的事，就是把这份台词本里的外语换成中文，时间一个字不动。翻译靠的是装在你自己电脑里的一小套翻译程序（就是上面说的「模型」，不用注册、不用开网页），全程不联网、不上传，你在看什么没有任何人知道。

还有个双语模式：同一条字幕，上面一行中文、下面一行原文，中文看剧情，觉得哪句不对劲就瞄一眼原文对照。

翻译完把文件改成和视频同名、放在同一个文件夹，大多数播放器会自动挂上。就这么简单。

## 和「听写生成字幕」的工具什么区别

分工不同。我另一个工具 [av-subtitles](https://github.com/lucasforster1108-boop/av-subtitles) 是片子根本没字幕时，靠听声音把字幕打出来。这个工具的前提是你已经有字幕文件，只是看不懂。没字幕先听写，有字幕来这里翻。

## 安装

需要 Python 3.9 以上。

```bash
pip install argostranslate
```

然后装你那对语言的模型包，下载一次、本地保存：

```bash
argospm update
argospm install translate-ja_zh   # 日语 -> 中文
argospm install translate-en_zh   # 英语 -> 中文
```

一个语言包大概 100–300MB，看语言对。没装语言包就运行，工具会直接停下来并把确切的安装命令打给你，不会假装翻译——我最烦那种悄悄失败的工具，所以这个宁可大声报错。

## 用法

```bash
# 日语字幕 -> 中文字幕，在源文件旁边生成 movie.zh.srt
python translate_srt.py movie.ja.srt --from ja --to zh

# 双语：中文在上、日语在下，同一条字幕内
python translate_srt.py movie.ja.srt --from ja --to zh --bilingual

# 自己指定输出路径
python translate_srt.py movie.en.srt --from en --to zh -o movie.chinese.srt
```

时间轴、字幕顺序、一条字幕内部的换行都保留，序号重新从 1 排齐。逐条翻译、绝不合并字幕，所以时间不会漂。

## 说实话的局限性

- 这是离线机器翻译，质量是「能看懂剧情」的级别，不是「能出版」的级别。专有名词、口语俚语、一语双关，翻车是常事。
- 长句子偶尔会被翻短、漏掉半句。原文句子短、断句干净的，翻译质量明显好一截。
- Argos 的语言覆盖不均匀：英/日/韩/西/法/德和中文之间的主流语言对都有；冷门语言对可能没有，有些语言对要经英语中转，质量再打折。
- 速度看 CPU。一部电影的字幕文件大概几分钟，不是几秒。
