# srt-translator

자막은 있는데 언어가 달라서 못 읽는 상황, 계속 겪었습니다. 일본어 영상에는 일본어 자막, 나머지는 대부분 영어 자막. 자막 파일 하나 때문에 번역가를 부를 수는 없고, 큐 800개를 웹 번역기에 하나씩 붙여 넣는 건 더 답이 없습니다.

그래서 기존 `.srt` 파일을 오프라인으로 번역하는 작은 도구를 만들었습니다. [Argos Translate](https://github.com/argosopentech/argos-translate)를 쓰고, 모델은 내 컴퓨터에서 돕니다. 타임스탬프는 손대지 않고 텍스트만 번역해서 새 `.srt`를 씁니다. 이중 언어 모드도 있습니다. 같은 큐 안에 번역이 위, 원문이 아래로 들어갑니다.

번역 과정에 네트워크는 쓰지 않습니다. 파일이 내 컴퓨터를 떠나지 않는데, 어떤 자막 컬렉션에서는 그 자체가 핵심입니다.

## 쉽게 말하면

성인 영상, 특히 일본 영상은 자막이 붙어 있는 경우가 많은데 일본어 아니면 영어뿐인 경우가 대부분입니다. 못 읽으면 대사는 추측뿐이고 장면의 절반은 그냥 지나갑니다.

자막 파일(`.srt`라는 파일)은 별 게 아닙니다. "몇 초에 어떤 대사를 하는지" 적어 둔, 시계가 달린 대본 같은 텍스트 파일입니다. 이 도구는 그 대본의 말만 중국어로 바꿔 겁니다. 시간은 한 글자도 안 건드립니다. 번역은 내 컴퓨터에 깔린 작은 번역 프로그램(위에 말한 "모델"이 이겁니다. 가입도 웹사이트도 필요 없습니다)이 하므로 인터넷에 연결하지 않고, 아무것도 업로드되지 않습니다. 내가 뭘 보는지 아무도 모릅니다.

이중 언어 모드도 있습니다. 같은 자막에서 윗줄은 중국어, 아랫줄은 원문이라 중국어로 따라가다가 이상한 줄은 원문과 비교할 수 있습니다.

번역한 파일을 영상과 같은 이름으로 같은 폴더에 넣어 두면 대부분의 플레이어가 자동으로 불러옵니다. 그게 전부입니다.

## 음성 받아쓰기 자막 도구와의 차이

하는 일이 다릅니다. 제 [av-subtitles](https://github.com/lucasforster1108-boop/av-subtitles)는 자막이 아예 없을 때 소리를 듣고 자막을 만드는 도구입니다. 이 도구는 자막 파일이 이미 있고, 단지 못 읽는다는 전제에서 출발합니다. 아무것도 없으면 받아쓰기, 파일이 있으면 여기서 번역, 이렇게 나눠 쓰면 됩니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install argostranslate
```

그다음 쓸 언어 쌍의 패키지를 설치합니다. 모델은 한 번 받으면 로컬에 남습니다.

```bash
argospm update
argospm install translate-ja_zh   # 일본어 -> 중국어
argospm install translate-en_zh   # 영어 -> 중국어
```

패키지 하나는 언어 쌍에 따라 대략 100~300MB입니다. 패키지 없이 실행하면 번역하는 척하지 않고, 멈춘 뒤 정확한 설치 명령을 출력합니다. 조용히 실패하는 도구가 싫어서, 이건 시끄럽게 실패하도록 만들었습니다.

## 사용법

```bash
# 일본어 자막 -> 중국어 자막, 입력 옆에 movie.zh.srt 생성
python translate_srt.py movie.ja.srt --from ja --to zh

# 이중 언어: 중국어가 위, 일본어가 아래, 같은 큐 안
python translate_srt.py movie.ja.srt --from ja --to zh --bilingual

# 출력 경로 직접 지정
python translate_srt.py movie.en.srt --from en --to zh -o movie.chinese.srt
```

타임스탬프, 큐 순서, 큐 안의 줄바꿈은 그대로 유지되고 번호는 1부터 새로 매깁니다. 번역은 큐 단위로 하고 큐를 합치지 않으므로 타이밍이 밀리지 않습니다.

## 솔직한 한계

- 오프라인 기계 번역입니다. 품질은 "장면이 이해되는" 수준이지 "출판 가능한" 수준이 아닙니다. 고유명사, 구어체, 이중 의미에서는 자주 틀립니다.
- 긴 문장은 짧게 번역되거나 절이 빠지기도 합니다. 원문 문장이 짧고 깔끔하게 끊긴 자막일수록 눈에 띄게 잘 번역됩니다.
- Argos의 언어 지원은 고르지 않습니다. 주요 쌍(영·일·한·스페인어·프랑스어·독일어와 중국어 등)은 있지만, 마이너한 쌍은 없을 수 있고, 영어를 경유하는 쌍은 품질이 떨어집니다.
- 속도는 CPU에 달렸습니다. 영화 한 편 분량이면 몇 분 걸립니다. 몇 초가 아닙니다.

## 테스트
