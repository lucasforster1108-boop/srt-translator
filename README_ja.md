# srt-translator

字幕はあるのに、言語が違うせいで読めない。日本語の動画には日本語字幕、それ以外はだいたい英語字幕。そういう場面に何度も出くわしました。字幕ファイルのために翻訳者を雇うのは大げさだし、800個のキューをWeb翻訳に一つずつ貼るのはもっと面倒です。

そこで、既存の `.srt` ファイルをオフラインで翻訳する小さなツールを作りました。[Argos Translate](https://github.com/argosopentech/argos-translate) を使い、モデルは自分のマシン上で動きます。タイムスタンプは一切変えず、テキストだけを翻訳して新しい `.srt` を書き出します。バイリンガルモードもあります。同じキューの中に、訳文を上、原文を下に並べます。

翻訳にネットワークは使いません。ファイルが自分のコンピュータから出ることはありません。人によっては、それ自体が大事なポイントだと思います。

## 平たく言うと

アダルト動画、とくに日本製のものには字幕が付いていることが多いのですが、日本語か英語だけということがほとんどです。読めなければセリフは当てずっぽうで、場面の半分が分からないままになります。

字幕ファイル（`.srt` というやつ）は大したものではなく、「何秒のところで、どのセリフを言うか」を書いた、時計付きの台本みたいなテキストファイルです。このツールは、その台本の言葉だけを中国語に置き換えます。時間は一文字も動かしません。翻訳は自分のコンピュータに入っている小さな翻訳プログラム（上の「モデル」のことです。登録もWebサイトも不要）が行うので、ネットには一切つなげず、何もアップロードされません。何を見ているか、誰にも知られません。

バイリンガルモードもあります。同じ字幕の上の行に中国語、下の行に原文を出すので、中国語で追いながら、怪しい行は原文と見比べられます。

訳したファイルを動画と同じ名前で同じフォルダに置けば、たいていのプレーヤーが自動で読み込みます。それだけです。

## 音声から字幕を作るツールとの違い

役割が違います。私の [av-subtitles](https://github.com/lucasforster1108-boop/av-subtitles) は、字幕が存在しないときに音声を聞き取って字幕を作るツールです。こちらは「字幕ファイルはもうある、ただ読めない」ことが前提です。何もなければ文字起こし、ファイルがあればここで翻訳、という分担です。

## インストール

Python 3.9 以降が必要です。

```bash
pip install argostranslate
```

次に、使う言語ペアのパッケージを入れます。モデルは一度ダウンロードすればローカルに残ります。

```bash
argospm update
argospm install translate-ja_zh   # 日本語 -> 中国語
argospm install translate-en_zh   # 英語 -> 中国語
```

パッケージは言語ペアによって 100〜300MB ほど。パッケージなしで実行すると、翻訳するふりはせず、止まって正確なインストールコマンドを表示します。黙って失敗するツールが嫌いなので、これはうるさいくらい正直に作りました。

## 使い方

```bash
# 日本語字幕 -> 中国語字幕。入力の隣に movie.zh.srt を生成
python translate_srt.py movie.ja.srt --from ja --to zh

# バイリンガル：中国語が上、日本語が下、同じキューの中
python translate_srt.py movie.ja.srt --from ja --to zh --bilingual

# 出力先を自分で指定
python translate_srt.py movie.en.srt --from en --to zh -o movie.chinese.srt
```

タイムスタンプ、キューの順序、キューの中の改行はそのまま保持され、番号は1から振り直されます。翻訳はキュー単位で、キューを結合することはないのでタイミングがずれません。

## 正直な限界

- オフライン機械翻訳です。品質は「場面が分かる」レベルで、「出版できる」レベルではありません。固有名詞、口語、掛け言葉では普通に失敗します。
- 長い文は短く訳されたり、一部が落ちたりすることがあります。原文が短くて文節がきれいな字幕ほど、明らかに良く訳せます。
- Argos の対応言語はばらつきがあります。主要なペア（英・日・韓・西・仏・独と中国語など）はありますが、マイナーなペアはない場合があり、英語を経由するペアは品質が落ちます。
- 速度は CPU 次第です。映画一本分で数分かかります。数秒ではありません。

## テスト

`tests/` には小さな英語サンプル字幕（公開の中立的な内容）、ラウンドトリップ検証（パース→書き戻しで情報を落とさないこと）、スタブ翻訳器によるバイリンガル構造のチェックが入っています。
